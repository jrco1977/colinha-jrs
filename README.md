# Colinha JRS — Eleições GO 2026

Painel interativo dos candidatos de Goiás nas Eleições 2026, um serviço da **JRS Soluções e Consultoria e Gestão Empresarial**.

- Busca e filtros por cargo, partido e nome
- Marque **Minha escolha** (salva no aparelho)
- Urna simulada e colinha para imprimir
- Link para compartilhar a chapa

Dados oficiais de divulgação do TSE. Este material não substitui a urna eletrônica.

Produção: [colinha-jrs.vercel.app](https://colinha-jrs.vercel.app)
